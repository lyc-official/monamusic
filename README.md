# MonaMusic website preview

Preview of the MonaMusic website (piano lessons with Mona Lim), shared for review before launch.

**Live preview:** https://lyc-official.github.io/monamusic/

This repository holds the built website only, published with GitHub Pages from the `main` branch. Some details are still being confirmed, so a few sections are left out for now. The enquiry form and WhatsApp button are switched off in this preview, and the pages ask search engines not to list them.
